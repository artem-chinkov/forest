# Почта леса / Forest Post — design handoff v0.3

**Статус:** проектная документация, визуальные SVG-макеты и исходные ассеты для Codex. Рабочее веб-приложение ещё не создано.

Кейс Amaya Soft: демонстрационный образовательный веб-продукт для детей 5–6 лет. В одном сюжете ребёнок помогает Ёжику-почтальону и учится определять начальный **твёрдый** звук [м] в знакомых словах на слух. Это только узкий первый vertical slice будущей платформы для 3–7 лет, а не полноценный курс чтения.

## Границы

Нет логина, платежей, backend, аккаунтов детей, записи голоса, таймеров или оценок уровня развития. Все данные — локальные и демонстрационные. Примерный порог 4/5 не является педагогической нормой. Тексты, словарь и аудио требуют согласования с методистом до тестирования с детьми.

## Технологический план

React + Vite + TypeScript + CSS, mobile-first для 390×844 и планшета, центрированная сцена на десктопе. Будущий адрес: https://artem-chinkov.github.io/forest/ . Для GitHub Pages используйте `base: '/forest/'` и Actions.
