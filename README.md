# Почта леса — проектная документация

Этот репозиторий содержит спецификацию и дизайн-материалы интерактивного веб-прототипа для тестового задания Amaya Soft. Само приложение ещё не реализовано.

Цель: за одно демонстрационное занятие показать распознавание начального твёрдого звука [м] у ребёнка 5–6 лет, процесс обучения, самостоятельную проверку и отчёт родителю.

См. `docs/00-index.md`, `AGENTS.md` и `docs/09-implementation-plan.md`. Методика и словарь нуждаются в экспертной педагогической проверке; MVP не предназначен для использования с реальными детьми без такой проверки.

Планируемый стек реализации: React + TypeScript + Vite; публикация через GitHub Pages (`base: '/forest/'`).
