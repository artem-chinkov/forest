# Лесная почта

**[Открыть прототип](https://artem-chinkov.github.io/forest/)** · [Репозиторий](https://github.com/artem-chinkov/forest)

Небольшая образовательная игра для примера 5–6 лет: знакомимся с буквой М, собираем посылку, придумываем слово и ловим открытки. Прототип подготовлен как иллюстрация рассказа о продукте для детей 3–7 лет; он не является курсом или диагностикой.

## Запуск локально

```sh
git clone https://github.com/artem-chinkov/forest.git
cd forest
npm start
```

Нужны Node.js 24+ и Python 3. Откроется `http://127.0.0.1:8765/demo/`. Установка npm-пакетов для приложения не требуется. На Mac можно открыть `Открыть демо.command`. Остановка — Control+C. Другой порт: `python3 tools/serve.py --port 8767 --open`.

## Управление и содержание

- На карточках нет написанных названий; доступны голос и повтор. Выбран синтетический голос Microsoft Dmitry. «Эм» — название буквы, не отдельный согласный [м].
- Посылка принимает два слова на М. Перетащите картинки или нажмите картинку, затем посылку. Подсказка раскрывает нужные варианты.
- Лампочка на речевом экране показывает четыре дополнительных примера. Ребёнок говорит вслух; микрофон не включается и ответ не проверяется.
- В ловле одновременно две или три открытки. За пять разных слов на М получаем пять конвертов, затем нажимаем на почтовый ящик. Пропущенные открытки возвращаются, проигрыша нет.
- Кнопка звука в шапке открывает переключатели музыки и эффектов. Музыка звучит на главном и в финале после первого взаимодействия; учебные задания проходят без неё.
- Круглая стрелка сбрасывает игру. Экран взрослого — удержание значка человека две секунды, также с клавиатуры.
- `?seed=42` воспроизводит набор. `?seed=42&presenter=1` открывает пульт показа; его результаты помечены как отдельный просмотр.

Все данные остаются в памяти страницы. Нет регистрации, записи речи, внешней аналитики и запросов к синтезатору во время игры. Словарь, озвучка и методика требуют проверки с методистом.

## Проверки и публикация

```sh
npm run check
npm test
npm run build
```

GitHub Actions запускает эти проверки при изменении `main` и публикует только статическую сборку `dist/` в GitHub Pages. Документация, тесты и инструменты генерации в сайт не входят. Корень `/forest/` открывает игру через `/forest/demo/`.

В репозитории оставлены используемые WebP, 63 WAV диктора, 7 WAV эффектов, одна музыкальная MP3-петля и тексты озвучки. Мастер-изображения, прежние версии и пробы сохранены в локальном архиве автора вне GitHub.

- [Маршрут и правила](docs/demo/README.md)
- [Сценарий видео на 3–5 минут](docs/demo/video-script.md)
- [Проверка и ограничения](docs/demo/qa.md)
- [Прослушивание букв и слов](docs/demo/audio-review.html) — открыть через локальный сервер

Для изменения озвучки редактируйте `content/audio-scripts.json`. Инструмент `tools/generate_audio_v2.py` использует зависимости из `tools/voice-requirements.txt`, доступ к онлайн-синтезу и штатный `afconvert` на Mac. MP3 кэшируются в `.cache/audio/`; голосовые инструменты не нужны для запуска игры или публикации готовых WAV.
