# Проверка «Лесной почты», v0.5

Дата: 16.11.2026. Проверяется текущий маршрут с пятью экранами и последними уточнениями пользователя: название буквы «эм» из одного символа М, общая инструкция упаковки и две–три открытки одновременно.

## Автоматические проверки

- `npm run check`: синтаксис пяти JS-файлов, изображения, все 63 WAV, PCM mono 22050 Hz / 16 bit, длительности и SHA-256.
- `npm test`: 18 проверок каталога, переходов, упаковки, помощи, воспроизводимого набора, видимых вариантов, начисления после озвучки, отправки, сброса и очереди аудио.
- `npm run build`: переносимая статическая копия в `dist/`, без публикации.
- `tests/browser.cjs`: полный путь; неверные картинки и помощь; перенос мышью, касанием и с клавиатуры; ошибка аудио и восстановление; пауза, скрытие страницы и сброс; пропуск и возвращение карточки; удержание взрослого; четыре размера; уменьшенное движение; выбор третьей карточки и сбор пяти целей без ожидания других.

Браузер: Chromium 159.0.8154.6 на macOS, headless Playwright. Для ускорения проверок голос воспроизводится быстрее только в тестовом окружении. В приложении обычная скорость. Касание моделируется браузерными touch-событиями; физические устройства и Safari не проверялись. Скрытие страницы моделируется visibilitychange.

Размеры: 320×568, 390×844, 1024×768, 1920×1080. Проверены загрузка изображений и отсутствие горизонтального переполнения. На небольшом экране допустима вертикальная прокрутка. В ловле при ширине <700 px две карточки, при ≥700 px три.

Результат: `qa-results.json`; снимки текущей версии — `previews/phone-letter.png`, `phone-packing.png`, `phone-speech-hints.png`, `phone-catch.png`, `tablet-catch.png`. Более ранние снимки с другими именами сохранены как история. Последняя проверка репозитория и пути `/forest/` — `final-verification.json`.

## Что проверяется как поведение

Правильные предметы не раскрываются общей инструкцией и показом жеста. Прослушивание не выбирает картинку. Дом и кот не упаковываются. Отправляется одна посылка после двух разных нужных предметов. Названия мыла и молока раскрываются подсказкой.

В ловле можно выбрать любую видимую карточку. Хотя бы одна цель доступна, пока остаётся в наборе. Все движения останавливаются при озвучке и паузе. Письмо начисляется после прозвучавшего названия, однократно; нецелевые слова не дают письма. После пяти разных целей открывается отдельная отправка. Пульт не подделывает результаты.

## Повтор браузерной проверки

Playwright требуется только разработчику, не приложению. При установленном Chromium и запущенном локальном сервере:

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/playwright node tests/browser.cjs
```

Другой порт: `DEMO_URL=http://127.0.0.1:8767/demo/`. Фильтр сценария: `QA_MATCH='выбор третьей'`. Для отдельного отчёта: `QA_REPORT=browser-results-focused.json`. Результаты создаются в игнорируемой папке `test-results/`.

## Ограничения

Пользователь утвердил название буквы, а не отдельный согласный: «эм» не выдаётся за [м]. Файлы и воспроизведение проверены технически; дикция, ударения, словарь и методика не прошли педагогическую валидацию. [Страница прослушивания](audio-review.html) позволяет сравнить буквы и слова. Прогресс игры не доказывает освоение навыка. Личное видео автора не записано автоматически; подготовлены текст и порядок показа.

## Финальный запуск из репозитория

Проверен отдельно: шесть реплик первого экрана завершились на обычной скорости 1.0; для М используется ровно один символ «М», тип реплики — название буквы. В активном наборе 63 WAV. Ошибок JavaScript, HTTP и внешних запросов нет. Сборка по префиксу `/forest/` загрузилась и показала три одновременные карточки на широком экране.

## Проверка музыки и эффектов

Дополнительные браузерные сценарии: `PLAYWRIGHT_MODULE=/path/to/playwright BROWSER=chromium node tests/soundscape-browser.cjs`, затем `BROWSER=webkit`. При другом адресе задайте `DEMO_URL`. Тестовые браузеры устанавливаются отдельно от приложения. Проверяются запуск по жесту, два переключателя и возврат фокуса, тишина в заданиях, остановка падения при настройках, порядок звуков финала, однократность акцента, отсутствие блокировки при 404 и четыре контрольных размера.

Перед видеозаписью прослушайте полный маршрут на обычной скорости: громкость, отсутствие щелчков и субъективный баланс на конкретных динамиках проверяются отдельно от автоматических тестов. Проверка на физическом iPhone не заменяется WebKit на компьютере.
