## Продуктовые события (только локальный demo event log)
`lesson_started`, `baseline_answered`, `baseline_skipped`, `training_answered`, `hint_used`, `audio_replayed`, `assessment_answered`, `assessment_skipped`, `assessment_completed`, `lesson_completed`, `parent_report_opened`, `session_reset`, `audio_error`.

Поля: `sessionId`, `mode`, `questionId`, `optionId`, `correct`, `assisted`, `hintUsed`, `timestamp`. Никаких имён детей, IP, записи голоса, реальной отправки серверу. В demo mode отдельный журнал без production влияния.

## Метрики
- Completion rate занятия.
- Доля правильных по B и T отдельно, справедливость сравнений **не доказана** при B=2, T=5.
- Доля assistance и replay.
- Технические error rates (audio, UI), UX трудности.
- Позднее: экспертно спроектированная повторная контрольная проба и наблюдение педагогов.

## Definition of Done
Три формата viewport без критических дефектов; QA01–QA20 зелёные или отдельно описанные ограничения; score из данных; JSON схема валидна; TypeScript чистый, build проходит; ссылка Pages доступна; demo mode отделён; нет несанкционированных внешних запросов.
