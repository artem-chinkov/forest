# Каталог оригинальных SVG-ассетов

В `../../public/assets/` находятся исходные SVG для выполнения упражнений. Всё artwork предварительное, предназначено для демо и нуждается в визуальной проверке на планшете/смартфоне.

- `characters/hedgehog-wave.svg`: приветствие
- `characters/hedgehog-thinking.svg`: подсказки
- `characters/hedgehog-happy.svg`: финал
- `backgrounds/forest-post-office.svg`: лес и здание почты
- `objects/parcel.svg`, `objects/mailbox.svg`, `objects/stamp.svg`: реквизит
- `objects/{word}.svg`: все 28 предметов из `../data/lesson.v1.json`, имена файлов кириллические. Использовать `encodeURI` или `new URL` при формировании путей, обязательно учитывать Vite base `/forest/`.

Рисунок `мама.svg` является иллюстративной человеческой фигурой и особенно нуждается в пилотной проверке, поскольку восприятие может быть неоднозначным. Карточки не должны содержать написанных слов, даже в alt-text видимом ребёнку. Для accessibility aria-label допускается на невидимом уровне.

SVG-макеты `../wireframes/*.svg` используют ссылки на эти файлы. Не превращать исходные SVG-макеты в UI background с невидимыми кликабельными зонами: строить настоящие доступные компоненты React/CSS.

Источники Amaya Kids использовать только как стилевые референсы; не копировать оригинальных персонажей и assets.
