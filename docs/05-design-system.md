# Визуальная дизайн-система v0.3

## Принцип
Оригинальная детская игра (не копия существующих персонажей Amaya). Тёплая лесная палитра, крупные предметы, плавное движение, чёткая иерархия, спокойное оформление кабинета родителя. Читаемые взрослые подписи, но детские варианты без написанных названий.

## Экранные размеры и композиция
- Mobile primary: 390×844 CSS px, safe area 16–20 px, нижнее CTA доступно без попадания под браузерную панель.
- Small mobile: 320×568, вертикальный скролл допустим, горизонтальный — нет; карточки могут перестраиваться.
- Tablet: 1024×768, игровая сцена в центре max-width 820; задачи в одной строке.
- Desktop: 1920×1080, центрированный canvas max-width 900, лесной декоративный фон по краям. Родительский контент max-width 760.
- Статичные макеты `wireframes/*.svg` имеют desktop-friendly landscape aspect и показывают телефонную игровую область как композицию. В реализации приоритет реальные CSS breakpoints.

## Цвета
- `--forest-bg: #EAF6E7` — детский фон
- `--forest-green: #5CAF89` — успех / акценты, не единственный сигнал
- `--pine: #315B43` — интерфейсные заголовки
- `--honey: #F7C66A` — основное действие
- `--honey-dark: #7A501B` — контраст текста на жёлтом

- `--paper: #FFFFFF` — карточки
- `--sand: #FFF8E8` — подсказка

- `--parent-bg: #F3F7FB`, `--parent-blue: #37658D`

## Типографика
Nunito (с системным sans-serif fallback). Детское сообщение 22–28 px, короткая инструкция 20–24, CTA 18–20 (вес 800), текст карточки для accessibility только aria-label, взрослый текст 16–18, взрослый заголовок 24–30, микро-тексты 12–14 только для взрослых / служебных меток.

## Сетка и компоненты
- Spacing: 4 / 8 / 12 / 16 / 24 / 32 / 40.
- Radius: 12 / 18 / 24 / 32.
- Primary CTA min-height 56 px, horizontal padding 24, ярко-жёлтая заливка.
- Choice card min 104×124 px для mobile при 3 колонках, на 320 px переразместить элементы/сократить отступы; интерактивные кнопки не менее 48×48 CSS px, большой запас для дошкольников.
- Speaker: круглая 48×48 внутри карточки, с подписанным aria-label («Прослушать: мыло»), card tap — выбор, speaker tap — ТОЛЬКО звук, без выбора (stopPropagation).
- Outline focus 3px, цвет #2F6784, контраст всегда проверяется.
- Status/selected: обводка 3px + изменение фона + icon, не полагаться на цвет.
- Модальные подсказки не закрывают правильные варианты во время выбора.

## Motion
- Button press 120–180 мс.
- Card select 150–240 мс.
- Parcel move 400–600 мс.
- Celebration ~1200 мс, без принудительного ожидания для продолжения.
- prefers-reduced-motion: мгновенные изменения без прыжков/параллакса.

## Audio UX
После пользовательского старта, с видимой кнопкой replay. Поддержка mute, если есть визуально доступный взрослый контрол. При отсутствии звука не засчитывать педагогическую пробу. Нельзя заменять ударение/фонемы произвольным TTS в реальном тестировании.

## Визуальная иерархия
1. Крупная инструкция/реплика Ёжика.
2. Ряд из 3 посылок/предметов.
3. Контрол прослушивания и помощь (только training).
4. Прогресс и вторичные действия.
5. Декоративный лес — не отвлекает.

## Оригинальные исходники
SVG в `public/assets/` — временные авторские векторные ассеты для сборки. В `wireframes/` — масштабные композиционные ориентиры. В `reference/` — ссылки на внешние примеры, не файлы для копирования.
