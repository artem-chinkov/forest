# Композиционные SVG-макеты

- `01-welcome.svg` — сюжет, Ёжик и большая кнопка. Baseline использует такую же композицию с карточками.
- `02-training.svg` — три иллюстрации, отдельные аудиокнопки, feedback/подсказка.
- `03-assessment.svg` — проверка 1/5, новая тройка слов, без подсказок/оценки ответа.
- `04-parent.svg` — взрослый отчёт: 4/5 в демо, подсказки, совет вне экрана.

Это исходные визуальные SVG (не HTML/CSS, не реализация). Их цель — задать иерархию, палитру, композицию и примерные пропорции; Codex обязан строить настоящий responsive UI, не использовать SVG-макеты как статическую картинку экрана.

Сопоставляйте с `../04-screen-specifications.md` и `../05-design-system.md`. Цвета, размеры и числа в макетах иллюстративны; JSON и документы главнее.
