# Четыре SVG-макета: mobile-first 390×844

Это композиционные SVG-макеты, **не исполняемый React/HTML/CSS**. Их можно открывать в браузере и графических редакторах. Для отображения вложенных оригинальных ассетов SVG следует просматривать из репозитория с сохранением относительных путей (в IDE/локальном браузере); встроенные GitHub-превью могут блокировать external SVG image references. При реализации Codex использует файловые ассеты напрямую.

- `01-welcome.svg`: сюжет, Ёжик, главный CTA. Baseline B01–B02 использует ту же сцену с карточками.
- `02-training.svg`: три карточки, аудио, retry и help.
- `03-assessment.svg`: пять последовательных проверочных задач без подсказок, финальная награда.
- `04-parent.svg`: взрослый отчёт и домашняя рекомендация.

Приоритет в случае конфликта: образовательная спецификация → JSON → экранная спецификация → дизайн-система → эти макеты. Макеты фиксируют композицию и токены, не замораживают layout на единственном разрешении.

Важное замечание: экраны являются **концептуальными** и не подтверждают фактическую педагогическую валидность заданий. В макетах кнопка «Отправить посылку» должна становиться доступна только после выбора карточки; в assessment подсказок нет.
