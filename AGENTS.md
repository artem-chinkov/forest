# Лесная почта

Рабочий прототип: HTML/CSS/JavaScript, пять учебных экранов для примера 5–6 лет. Актуальный маршрут и ограничения — `docs/demo/README.md`.

- Сохранять маршрут: буква М и мыло → молоко → упаковка слов на М → своё слово → ловля открыток → награда → отчёт.
- Голос Microsoft Dmitry утверждён пользователем. В синтез передавать один символ «М»: название буквы «эм», не отдельный [м]. Тексты — `content/audio-scripts.json`, готовые WAV — `public/assets/audio/demo-v2/`. Генерация только при подготовке ассетов, не в браузере.
- До подсказки инструкция упаковки не раскрывает мыло и молоко. После двух неподходящих картинок или ручной помощи их можно показать и назвать. Дом и кот не принимаются.
- Каталог — `demo/catalog.js`: нужны все 28 картинок. В ловле одновременно две карточки при ширине <700 px и три при ≥700 px; среди видимых есть цель, пока цели остались. Конверт начисляется после озвучки, однократно; отправляются пять писем.
- Не добавлять названия на детские карточки. Сохранять управление мышью, касанием и клавиатурой, повтор, паузу, восстановление аудио, уменьшенное движение и сброс.
- Не использовать микрофон, распознавание, аккаунты или удалённую аналитику. Состояние только в памяти. Устный ответ не оценивается; игровой прогресс не доказывает освоение навыка.
- Проверять `npm run check`, `npm test`, `npm run build`; браузерные сценарии — `docs/demo/qa.md`. Контрольные размеры: 320×568, 390×844, 1024×768, 1920×1080.
- GitHub Pages публикует только `dist/` после проверок в `main`. Проверять пути `/forest/` и `/forest/demo/`. Внешние изменения выполнять в пределах поручения пользователя.
- Исторические материалы и мастер-изображения вынесены в проверенный локальный архив автора. Не возвращать их в репозиторий без необходимости; кэши и результаты проверок не коммитить.

- Музыка и эффекты — `demo/soundscape.js`, файлы и лицензии — `public/assets/audio/soundscape-v1/`. По умолчанию включены. Музыка только на главном после жеста и после финальной реплики/акцента. Учебные экраны и отчёт без музыки. Декоративное аудио не блокирует урок, не перекрывает диктора и не меняет прогресс. Настройки только в памяти страницы.
